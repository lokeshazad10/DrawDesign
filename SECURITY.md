# Security Policy

## Supported versions

Security fixes are intended for the latest released version of DrawDesign. Older releases are
not currently supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Use
[GitHub's private vulnerability reporting](https://github.com/lokeshazad10/DrawDesign/security/advisories/new)
if it is enabled for this repository, or contact **[maintainer security contact placeholder]**.
Do not open a public issue for an unpatched vulnerability. Include the affected version, impact,
and steps to reproduce, without sharing real user data or secrets.

## Response expectations

We aim to acknowledge reports within 3 business days and provide an initial assessment or status
update within 7 business days. Investigation and fixes may take longer depending on severity and
complexity; we will communicate material updates as we can.
